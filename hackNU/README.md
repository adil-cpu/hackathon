# Zaman Bank AI Assistant — HackNU 2025 (18–19.10.2025)

Проект сделан на хакатоне HackNU 2025 по кейсу Zaman Bank.

Активная ссылка (Live Demo): [https://hackathon-topaz-eight.vercel.app/](https://hackathon-topaz-eight.vercel.app/)

Сайт отвечает только тогда, когда запущен n8n-воркфлоу (бэкенд). Как запустить его у себя — в разделе [Как запустить](#как-запустить).

## 🚀 О проекте

Чат-ассистент для клиентов банка. Отвечает на вопросы о продуктах Zaman Bank (депозиты, кредиты, инвестиционные продукты) строго по базе знаний в Google Docs и не придумывает условия, которых там нет. Помогает с финансовыми целями: разбить цель на шаги, посчитать, сколько откладывать в месяц, подобрать подходящий продукт банка.

Как это устроено:

* Фронтенд — веб-страница с чатом на HTML, CSS и чистом JavaScript. Есть голосовой ввод (Web Speech API). Задеплоен на Vercel.
* Бэкенд — воркфлоу в n8n. LLM-агент на модели Google Gemini берёт ответы из документа Google Docs с базой знаний банка и помнит последние 10 сообщений диалога (Simple Memory).
* Сайт связан с n8n через webhook: страница отправляет сообщение POST-запросом, n8n возвращает ответ агента. Во время хакатона n8n работал локально и был доступен через туннель ngrok.

## 🛠 Что было использовано (Технологии)

* HTML5: Для создания структуры веб-страницы (index.html).
* CSS3: Для стилизации и оформления (style.css).
* JavaScript (ES6+): Для реализации интерактивности и логики приложения (app.js).
* n8n: Логика ИИ-ассистента — LLM-агент, Google Gemini, Google Docs, память диалога (HachNU.json).
* ngrok: Туннель, через который сайт обращался к локальному n8n.
* Vercel: Платформа для хостинга и развертывания проекта.

## 📁 Структура проекта

* index.html: Главный HTML-файл, точка входа в приложение.
* style.css: Файл со стилями.
* app.js: Основной файл с JavaScript-логикой.
* HachNU.json: Файл (workflow) n8n.

## Как запустить

1. Установите n8n (например, через `npx n8n` или Docker).
2. Импортируйте воркфлоу из файла `HachNU.json` (в n8n: Import from File).
3. Подключите учётные данные:
   * Google Gemini (PaLM) API — для узла Chat;
   * Google Docs OAuth2 — для узла «Get a document in Google Docs». В этом же узле укажите ссылку на свой документ с базой знаний.
4. Активируйте воркфлоу и скопируйте Production URL из узла Webhook.
5. Если n8n запущен локально, откройте к нему доступ из интернета, например через ngrok: `ngrok http 5678`.
6. В `app.js` замените значение `N8N_WEBHOOK_URL` на свой адрес webhook.
7. Откройте `index.html` в браузере или задеплойте папку на Vercel.
